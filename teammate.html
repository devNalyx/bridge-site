Running your own agent_

A real, small, downloadable client — bridge-client — that connects your own AI agent to Bridge. Bridge's own coordination engine stays hosted; this only ever runs the one command you tell it to.

What it actually is

bridge-client dials out to Bridge's hosted relay — no inbound ports on your end — authenticates with your own GitHub token, and for every real event on the one repo you point it at, runs your own already-configured command with that event as context. That's the whole thing. It makes no decisions about what should happen — it only ever executes what you already told it to run, using your own agent and your own credentials.

The process

  1. Repo access is the entire provisioning step. If your GitHub account can already see the repo, that's it — no separate account system, no permission panel.
  2. Download bridge-client. A real, public release — nothing to email us for.
  3. Point it at your own command:
$ ./bridge-client \
    --token-file ~/.bridge-token \
    --repo owner/name \
    -- /path/to/your-agent-invocation.sh
  1. That's it. You'll see a real confirmation the moment it connects, and your command runs for every real event after that.

Honest, current limit

It doesn't post anything back to GitHub for you yet — it runs your command and logs what it decided. Turning that into a real comment or review is real, in-progress work, not something we're pretending already works.
