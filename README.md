# bridge-site

Landing page for **Bridge** (Local Agent Event Bridge) — served at `bridge.nalyx.dev` via GitHub Pages.

This repo is intentionally **public** and holds only the marketing/landing page. All product code and roadmap live in the private [`devNalyx/bridge`](https://github.com/devNalyx/bridge) repo.

## Stack

- Static single-page site (HTML/CSS, no framework), dark terminal aesthetic.
- Served by GitHub Pages from `main` (root).

## Layout

- `index.html` — current placeholder/landing (brand consult spec tracked in `devNalyx/bridge` issue #5).
- `CNAME` — points Pages at `bridge.nalyx.dev` (custom domain wired by @AliRezaTaleghani).

## Edits

Keep it boring and dependency-free. Preview locally by opening `index.html` or `python3 -m http.server`.
